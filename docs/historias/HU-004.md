# HU-004: Enviar las lecturas pendientes sin duplicarlas

**Como** técnico de EPMAPS
**quiero** que las lecturas pendientes se envíen solas cuando haya conexión, y ver cuántas faltan
**para** que la oficina reciba cada lectura una sola vez, sin tener que hacer nada.

## Criterios de aceptación de alto nivel
- Al recuperar la conexión, las lecturas pendientes se envían sin intervención mía.
- Si la señal se corta durante un envío, la lectura llega una sola vez a la oficina.
- En todas las pantallas veo el estado de conexión y el número de lecturas pendientes.
